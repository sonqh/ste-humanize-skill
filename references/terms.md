# Technical terms and other languages

Read this file when the text is not in English, or when it holds domain terms or identifiers.

## Technical terms and other languages

Keep established technical terms as they are. Do not translate them word by word or swap them for a plainer word that loses meaning. "Source of truth", "idempotent", "lockfile", "schema", "hook" stay in English in any language. When a product name, file name, command, flag, or config key stays in the text, keep it exact. Do not translate or paraphrase it. `## Audience fit` in `references/human.md` decides whether a source-level identifier stays at all.

- Define a term the reader may not know once, on first use. After that, use the term alone.
- Pick one term per concept. Do not alternate with a translation.
- In another language, apply every sentence rule and every AI tell in that language. "Không phải X mà là Y" is the same tell as "not X but Y".
- Translate only ordinary words. "Thư mục" for directory is fine. "Nguồn chân lý" for source of truth is not.
- In Strict mode, keep the exact identifier, error code, or API name the system uses. Audience fit does not remove identifiers in Strict mode.
- Suggest a one-line glossary entry for a domain term that must stay.
