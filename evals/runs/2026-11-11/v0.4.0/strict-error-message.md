Error UPL-413: The file upload failed.

The cause may be one of these:

- The file is larger than the 25 MB limit.
- The storage quota was exceeded.

You can compress the file. Then you can upload the file again.

Do not retry more than 3 times. More retries may lock the account temporarily.

Kept as-is: "may be" for the cause and "may lock" for the account, because the source does not confirm the cause or the lock. "was exceeded" stays passive because the source does not name the actor.
