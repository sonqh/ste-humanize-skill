Subject: Offline mode for the mobile app

Hi Tom,

We will not build an offline mode in 2027. Handling sync conflicts, where the phone and the server hold different versions of the same record, costs too much to build.

Two things exist today for drivers who lose signal:

- Draft save has been on since app version 4.2. When the network drops, the delivery form saves a draft on the phone and sends it when the signal returns. This works only for a form that the driver opened before the signal was lost.
- You can print the route sheet of the day from the web dashboard (Routes > Print).
