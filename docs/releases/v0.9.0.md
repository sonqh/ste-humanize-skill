# v0.9.0: tells of decision pages

## For users

- The skill names six habits of a model that writes an ADR, a design doc, or a proposal. One example is a page that weighs each option and picks none. Others are a quality word with no number, and a risk answered with "we will watch it".
- The linter flags four of them as advisory: `false-balance`, `actorless-decision`, `empty-mitigation`, and `unmeasured-quality`. An advisory finding does not fail the run.
- A review of a decision page checks for the six habits.

## Install or update

