# v0.5.0: reader first, shorter SKILL.md

The skill now starts from the reader, and `SKILL.md` is shorter. These notes cover versions 0.4.0 and 0.5.0. Neither had a release.

## For users

- You can ask for a new page from notes, code, or a diff. The skill works out who reads the page and selects the content for that reader.
- The answer comes first. The first sentence gives the conclusion, the decision, or the action.
- A list appears only where it fits. Parallel parts and steps become a list. Reasoning stays a paragraph.
- A rewrite removes no idea of yours. The skill names a part the reader may not need on a `Cut candidates:` line. You decide.
- The linter has three new advisory rules for shape: `long-paragraph`, `inline-list`, and `buried-sequence`. They never fail a run.

## For maintainers

- `SKILL.md` went from 2795 words to 1807. Rules for one case moved to `references/`. A table in `SKILL.md` says which file to read.
- An agent in Human mode reads `references/ai-tells.md` only when the source sounds like a chatbot, or when a phrase is in doubt.
- `evals/` holds fixtures and a scorer for text that an agent wrote with the skill.

## Install or update

```
/plugin install ste-humanize --marketplace sonqh/ste-humanize-skill
/plugin update ste-humanize@sonqh
```

The update applies after a restart of Claude Code.
