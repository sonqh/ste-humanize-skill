# v0.5.1: a more exact Reader line, and the first task before the reference

## For users

- The skill adds a `Reader:` line only when your request does not name the reader. Before, it could add the line to a tool description or an error message, where the request already says who reads the text.
- A README written from notes now puts the lookup detail under one `Reference` heading at the end. That detail is the exit codes, the limits, and the full list of flags. The install command and the first example stay near the top.

## Install or update

```
/plugin update ste-humanize@sonqh
```

The update applies after a restart of Claude Code.

## How to publish this release

```bash
gh release create v0.5.1 --target main --title "v0.5.1: a more exact Reader line" --notes-file docs/releases/v0.5.1.md
```
