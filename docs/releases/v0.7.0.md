# v0.7.0: documents for work that is not built yet

## For users

- Ask for a design doc, and the skill orders it by the questions of its reviewers. It starts with the problem, the goals, and the non-goals. The options include "do nothing". The page ends with the rollout and the open questions.
- On a page about work not built yet, the skill marks each number as measured, an estimate, a target, or an assumption.
- When your notes do not give a number, a date, or an owner, the skill writes `TBD` with an owner and a date. It does not invent the value. A `Missing:` line after the text lists each gap.
- An ADR that the team has not decided yet gets the status Proposed, the person who decides, and the date. It names the criteria before the options.

## Install or update
