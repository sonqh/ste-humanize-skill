# v0.6.0: page guides for a README, an ADR, and a technical proposal

## For users

- Ask for an ADR, a README, or a technical proposal, and the skill orders the page by the questions of its readers. The title of an ADR states the decision. A proposal opens with the request, the cost, and the date.
- For any other document, the skill lists the questions that the reader brings and gives each one a section.
- A rewrite of a whole page can now move a part to the place where the reader looks for it. It removes no fact.
- When your repository has a template for a kind of page, the skill keeps its headings and their order.

## Install or update

```
/plugin update ste-humanize@sonqh
```

The update applies after a restart of Claude Code.
