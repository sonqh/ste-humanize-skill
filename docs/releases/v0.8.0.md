# v0.8.0: review of a page

## For users

- Ask the skill to review a design doc, an ADR, a proposal, or a README. It does not rewrite the page. It tells you what is missing for the reader.
- The review starts with a verdict: ready or not ready, for the reader that you name. When the page is not ready, the verdict names the gap that stops the reader most.
- A table checks each question of that reader: answered, partly, or not, and where.
- Up to seven other findings follow, the most severe first. Each one names the place and a fix. The last line gives the result of the linter.
- When you want the rewrite after the review, ask for it.
