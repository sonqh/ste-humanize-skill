## One correction to a fixture

The Strict fixture first allowed only a `Kept as-is:` line. All 6 runs added a `Cut candidates:` line, and the skill permits that line in a Rewrite in both modes. The fixture was wrong, and it now allows the line. The scores in the table use the corrected fixture.

## Open questions for the owner

1. How long may a page be? The word limits of the long fixtures are guesses. The README from notes is the clearest case: the notes have 793 words and the outputs have 695 to 755. The agent left out every internal detail and kept every fact a user can act on, as the skill says. The fixture also requires 24 of those facts, so its limit of 560 words fights its own fact list. If a README must be shorter, the skill needs a rule that moves reference detail to a second page.
2. Should the rule for the `Reader:` line be more exact? The rule says to add the line when the writer cannot ask and chooses the reader. The runner prompt says that the agent cannot ask. An agent can read that as the trigger, even when the request names the reader.
