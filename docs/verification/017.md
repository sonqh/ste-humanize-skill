## Eval run

Six fixtures cover three cases, each in English and in Vietnamese:

- a chat reply to an upset user who is not technical, after a double charge
- an email to a customer from an engineering note that gives a hedged date and says "Don't promise Friday"
- a refusal of a feature request by email.

Each version ran three times. In each run, one agent wrote all six outputs in the same order. The outputs are in `evals/runs/2026-11-17-messages/`.

The word counts of the Vietnamese fixtures count syllables.

- Chat length is the largest change. Each reply of 0.9.0 to the upset user had four paragraphs and explained the cause. Each reply of 0.10.0 had three or four sentences: the problem, the refund, and the 5 to 10 days.
- Both versions kept the hedge on the date of the fix. No run promised Friday. All three runs of 0.10.0 named the date of the next update on a `Missing:` line in both languages. One run of 0.9.0 did that.
- In the refusal, all runs of 0.9.0 thanked the customer before the no. One run of 0.10.0 in each language did the same.
- In Vietnamese, 2 of 3 runs of 0.9.0 called the customer "chị", but the request gives no gender. All runs of 0.10.0 used "mình" and "bạn", the default of a chat when the customer gives no pronoun.
- No run of either version used a stock phrase from the lists, in either language.

## The first run

The first scoring changed the check of the two refusal fixtures, as 017/D15 says. Each email opened with a subject line, and the scorer read "Subject:" as the first sentence. The check `answer-first` failed in every run of both versions. The fixtures now ask that the no starts in the first 16 words in English and the first 18 in Vietnamese. The author set these limits after reading the outputs. No agent ran again.

## Limits of the run

- Three runs for each version, six fixtures, and one agent for the six fixtures of a run. A fixture can see the one before it.
- The author of the fixtures also wrote the rules.
- One run of 0.10.0 wrote "I have also asked our engineers to stop this". The note says only that a ticket is open. The skill did not catch this added fact.
- The Vietnamese outputs got no check of sentence length. Change 018 can add one.
- The author read all 36 outputs of the upset-user and refusal fixtures, and the date sentences of the 12 outputs of the engineering note.
