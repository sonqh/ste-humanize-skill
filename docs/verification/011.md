- `handoff write` drops the questions of an old `handoff.md` when `.ctx/questions.json` already exists. A plan stop on the first change after an upgrade causes that order.

- `gate` skips the rule `synonym-rotation`. `specctx lint ste` and `scripts/lint.py` report it as hard. The repository rule asks for 0 hard findings from `scripts/lint.py`, so the gate alone does not enforce it. Version 0.1.1 did the same.
